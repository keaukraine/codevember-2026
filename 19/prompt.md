# Goal

Create a Codevember 2026 entry with a theme "Erosion"


## Implementation

Create a 3D scene with desert and procedurally generated eroded rock.
Scene must not be empty - also must have proper mid-ground and background.
Add as many suiting details as needed - sand, wind, etc.

Sample photos of rocks are in sample1.png sample2.png sample3.png.


Add various customization options for all scene objects and aspects.

Use modern cool post processing effects.

Use Disney animation principles for animated objects, if any.

Use max effort for the best visuals.

## Tech details

Use Three.js and any other necessary libraries.
Use lil-gui for customization options.
