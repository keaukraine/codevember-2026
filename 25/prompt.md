# Goal

Create a Codevember 2026 entry with a theme "Veil"


## Implementation

Create a 3D scene with intricate semi-transparent veil falling on the human figure.
Human figure is totally invisible - only veil reveals its shape.
Scene is completely black and white.
Strong vignette, film grain, etc.
Veil can be picked by mouse and dragged.

Add various customization options for veil size, cloth material, gravity, reset (drop veil again), debug option to show invisible human figure etc.

Use modern cool post processing effects.

Use Disney animation principles for animated objects, if any.


## Tech details

Use Three.js and any other necessary libraries.
Use lil-gui for customization options.
Use the best suitable library for physics.
