# Goal

Create initial structure for "Codevember 2026".


# Implementation

Create a directories named from 1 to 30, representing days of November 2026.

Each directory should have an HTML page template with name for each Codevember experiment and links to navigate to next and previous ones.
Each directory will have daily creative agentic coding experiments for November 2026.
Pages should share all the same common layout. Currently they should have empty gray background and placeholder text "Nothing here".
